Jendela Browser Chromium Telah Terbuka!

Browser FastMoss asli sedang berjalan di layar komputer Anda.

Langkah yang perlu Anda lakukan:

  1. Buka jendela browser Chromium baru yang baru saja muncul di layar Windows Anda (cek taskbar bawah bila berada di belakang jendela lain).
  2. Di browser tersebut, klik tombol "Masuk / Login" di pojok kanan atas FastMoss.
  3. Masukkan email & password akun FastMoss Anda hingga berhasil masuk ke Dashboard.
  4. Setelah berhasil masuk, kembali ke halaman web ini dan klik tombol hijau di bawah ini:

Sesi Login FastMoss Aktif (noVNC Virtual Display)

Silakan masukkan email, password, dan verifikasi captcha FastMoss di layar browser bawah ini. Setelah Anda berhasil masuk ke Dashboard FastMoss, klik tombol hijau "Simpan Sesi & Tutup" di atas.

Bagaimana Cara Login FastMoss Bekerja?
  1. Di Komputer Lokal (Windows): Tombol di atas akan membuka jendela browser asli di desktop laptop Anda. Setelah Anda selesai login di browser tersebut, cukup klik tombol "Simpan Sesi & Selesai".
  2. Di Server VPS (Ubuntu/Linux): Sistem otomatis menggunakan display virtual (Xvfb) dan noVNC streaming, sehingga Anda bisa login langsung di dalam halaman web tanpa install software VNC tambahan.
  3. Cookie sesi Anda disimpan dengan aman sebagai storage_state.json dan dipakai otomatis oleh seluruh job antrean.
